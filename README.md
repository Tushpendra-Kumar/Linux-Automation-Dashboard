## 📌 Overview

The **Linux Automation Dashboard** is a web-based infrastructure management and DevOps orchestration tool. Powered by **Python Flask** and **Ansible**, it enables system administrators and developers to monitor server telemetry, execute automated playbooks, and manage remote Linux nodes through a centralized graphical interface.

---

## ✨ Key Features

- **Server Telemetry & Metrics:** Real-time monitoring of CPU load, memory utilization, disk space, and active processes.
- **Ansible Playbook Orchestration:** Run configuration management scripts and automated system setup across nodes with one click.
- **Service Status Management:** Start, stop, and restart essential Linux systemd services directly from the browser.
- **Clean Responsive UI:** Lightweight HTML5/CSS3 templates for rapid, low-overhead server monitoring.

---

## 💻 Tech Stack & Architecture

- **Backend Engine:** Python 3.x, Flask Framework
- **Automation & DevOps:** Ansible, Bash / Shell Scripting, Systemd
- **Frontend UI:** Jinja2 Templates, HTML5, Modern CSS3

## 🚀 Getting Started

### Prerequisites
Python 3.8+, pip, and Ansible installed on a Linux host.

### Installation & Setup
```bash
# 1. Clone this repository
git clone https://github.com/Tushpendra-Kumar/Linux-Automation-Dashboard.git

# 2. Navigate into project directory
cd Linux-Automation-Dashboard

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run Flask application
python app.py
```
